## 概要
このアプリケーションは、ユーザーが1日の振り返りをするための Web アプリです。Next.js と Supabase を用いた認証機能や、感情レベル（落ち込み・落ち込み気味・普通・元気・とても元気）を可視化するコンポーネントを備えています。ユーザーはログインして日々の気持ちを記録し、振り返ることができます。

## 動作環境
- Node.js 18.x
- npm 9.x
- Next.js 13.x
- Supabase

## 環境構築
- リポジトリをクローン後、以下のコマンドで依存関係をインストールしてください。
```
nmp install
```
- Next.js の開発サーバーを起動します。
```
npm run dev
```

## デプロイ
NetlifyでCI/CDを構築しているため、Githubにpushすると自動デプロイできます。
ただし、以下のコマンドでビルドして、TypeScriptの型エラー等が発生してビルドができないことがないか事前に確認してください。
デプロイが完了したら、Netlifyの該当デプロイで「publish deploy」を選択してデプロイを公開してください。

```npm
npm run build
```

## 使い方
日記ページでは、気持ちと感情レベルを入力して記録できます。

## 注意事項
環境変数は .env.local などで設定してください。

## 実装予定
1. 環境変数を使用したリダイレクトURL設定
1. Next.jsでは静的コンテンツを自動でキャッシュしているか確認
1. DBデータをキャッシュした方が安く運用できるか確認
1. 今の気持ちを10メモリに変更
1. Googleカレンダーと連携して、時間ブロックして予定を入れられるようにする
1. AIを好きなモンスターキャラ化して楽しく話せるようにする
1. 日記の検索機能
1. 元気メーターのグラフ化

## 不満・要望
1. テンプレ追加時のダイアログをもっと上に表示しないと、キー入力ボードと被って保存ボタンが押しにくい
1. 今の気分の再編集ができないので、できるようにする
1. テンプレの編集したら、新規テンプレが作成されてしまうので、修正する
1. 最後に選択した今の気分をキャッシュして、同じ設定で日記を書きやすくする
1. テンプレ内でスクロールができないを改善
1. 入力テキスト内でマークダウン記法が使えること

## 実装するかもしれないこと
1. バックエンドコードをオニオンアーキテクチャ化
1. Dockerで環境構築
