# 日記テンプレート機能仕様書

## 概要
ユーザーが日記を効率的に作成できるよう、カスタマイズ可能なテンプレート機能を提供します。
テンプレートを使用することで、日記入力欄に事前定義したテキストを自動的に挿入することができます。

## 機能詳細

### 1. テンプレートの作成と管理
- ユーザーは設定画面でテンプレートを作成・保存できます
- 各テンプレートは以下の要素で構成されます：
  - テンプレート名：テンプレートを識別するための名前
  - テンプレート内容：日記入力欄に挿入される実際のテキスト

### 2. テンプレートの使用
- 日記入力画面（「今日はどんな一日でしたか？」の入力欄）で、保存済みのテンプレートを選択できます
- テンプレートを選択すると、そのテンプレートの内容が入力欄に自動的に挿入されます

## テンプレート機能の利点
- 日記作成の効率化：定型的な内容を都度入力する手間を省きます
- 一貫性の維持：同じ形式で日記を書くことができます
- カスタマイズ性：ユーザー自身が必要なテンプレートを作成できます

## 技術仕様

### データ構造
```typescript
interface JournalTemplate {
  id: string;        // テンプレートの一意識別子
  userId: string;    // テンプレートの所有者ID
  title: string;     // テンプレート名
  content: string;   // テンプレート内容
  tags: string[];    // 関連タグ（オプション）
}
```

### 保存場所
- テンプレートデータはSupabaseの`user_settings`テーブルの`journalSettings`カラム内に配列として保存されます
- ユーザーごとに複数のテンプレートを保存可能です
