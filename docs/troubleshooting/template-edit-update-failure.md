# テンプレート編集時の更新失敗と新規作成の問題

## 問題

テンプレート編集画面（TemplateDialog）で既存のテンプレートを編集し保存しても、テンプレートが更新されず、代わりに新しいテンプレートが作成されてしまう。

## 原因

1.  **`TemplateDialog` コンポーネントから `handleSaveTemplate` 関数への `id` の受け渡し**:
    *   編集ボタン押下時のハンドル関数(handleEditTemplate)でidを渡していなかった。

2.  **`updateTemplate` 関数の `id` の扱い**:
    *   `lib/journal.ts` の `updateTemplate` 関数に編集ボタンで選択したテンプレートの`id` がわたっていなかった。

## 解決方法

1. コミット「テンプレート管理機能の改善: テンプレートの更新処理を追加し、型定義を整理。ダイアログの初期値設定を修正。」のID「c60b7819c8f93f4f4359a13c0c3ecc2734a3a50a」を参照

2. 重要なポイント：

   *   `TemplateDialog` から `handleSaveTemplate` に常に `id` が渡されるようにする。

## 今後の注意点

*   コンポーネント間でデータをやり取りする際に、必要なプロパティが正しく渡されているかを確認する。
*   既存のデータを更新する際には、更新対象の `id` が正しく指定されていることを確認する。
