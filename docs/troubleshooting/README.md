# トラブルシューティングガイド

このディレクトリには、開発中に遭遇した問題とその解決方法をドキュメント化しています。
将来、同じような問題が発生した際に、素早く解決できるようにすることを目的としています。

## ディレクトリ構造

```
troubleshooting/
├── README.md
├── database/          # データベース関連の問題
├── frontend/         # フロントエンド関連の問題
└── deployment/       # デプロイメント関連の問題
```

## ドキュメントの探し方

1. **エラーメッセージで検索**
   - 各ドキュメントにはエラーメッセージが含まれています
   - リポジトリ内検索で該当するドキュメントを見つけることができます

2. **タグで探す**
   - 各ドキュメントの末尾にはタグが付いています
   - 例: #supabase #database #migration など

3. **カテゴリで探す**
   - データベース関連 → `database/`ディレクトリ
   - フロントエンド関連 → `frontend/`ディレクトリ
   - デプロイメント関連 → `deployment/`ディレクトリ

## ドキュメントのテンプレート

新しい問題に遭遇した際は、以下のテンプレートを使用してドキュメントを作成してください：

```markdown
# [問題の簡潔なタイトル]

## 発生日時
YYYY/MM/DD

## 問題
- エラーの内容
- 発生状況

## 原因
問題の根本的な原因

## 試したこと
1. 試した対処法1
2. 試した対処法2

## 解決策
実際に効果のあった解決策

## 学んだこと
この問題から得られた教訓

## 関連ファイル
- 関連するファイルへのパス
- 参考にしたドキュメントへのリンク

## タグ
#関連タグ
```

## 注意事項

- ドキュメントは具体的なエラーメッセージや事象を含めてください
- 解決に至るまでに試したことも記録してください（他の人が同じ試行錯誤を避けられるように）
- 関連するコードスニペットは必ず含めてください
- タグは適切なものを選んでください
